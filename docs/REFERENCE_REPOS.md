# BIT-HUNTER 2099 — External Reference Repositories

For mini-game mechanics implementation, the following reference repositories have been cloned alongside this project (`D:\03_Projects\GAME-DEV\`):

1. **`ref-flappy/`**
   - **Upstream**: [https://github.com/usmansbk/flappy-bird](https://github.com/usmansbk/flappy-bird)
   - **Role**: Reference implementation for Block Flyer (flap impulse, pillar generation, gap spacing, and Arcade physics boundaries).
   
2. **`ref-pacman/`**
   - **Upstream**: [https://github.com/ourcade/pac-man-ghost-ai-phaser3](https://github.com/ourcade/pac-man-ghost-ai-phaser3)
   - **Role**: Reference implementation for Vault Run (Phaser 3 ghost state machines, tile grid targeting for Blinky/Pinky/Inky/Clyde styles, and power pellet frightened mode).

*Note: Per project architecture rules, only game logic and algorithms are referenced. Neither repository is copied or merged as a whole project.*
