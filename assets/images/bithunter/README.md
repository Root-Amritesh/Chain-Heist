# BIT-HUNTER asset pack
Cut from the 5 concept images. Backgrounds made transparent, watermark removed.
Put this folder at: bit-hunter-game/assets/images/bithunter/

- maps/neo-city.png: 1920×1152 (120×72 tiles of 16px). Hub background for the Tiled Image Layer.
  maps/neo-city-original-res.png: the same map at full resolution.
  The HP bars and district labels were painted out. A few soft smudges remain where labels were.
- characters/: cat-1..5 (player/hunters), npc-01..18
- enemies/: ape-1..5 (hacker apes)
- items/: coins (gold, green, ETH, stacks)
- props/: signs, ATM, terminals, rigs, servers, barrels, crate, PCs, etc.
- flyer/: Block Flyer pillars, server tower, drone, background chunks, ground strip
- ui/: logo, HP bars, panels, icons, cursor
- preview-sprites.png / preview-map.png: contact sheets

Notes: all sprites are single front-facing frames (no walk cycles). Sizes vary, so scale in-game.
